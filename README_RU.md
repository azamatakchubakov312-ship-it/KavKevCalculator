# KAV&KEV — калькулятор заказа для Android

Приложение на Kotlin + Jetpack Compose. Товары и цены внесены по фотографии прайс-листа.

## Возможности
- Категории: сэндвичи и фастфуд, яйца/сметана/масло, сыры.
- Поиск товара.
- Количество каждого товара: кнопки `+` / `−` или ручной ввод.
- Автоматическая сумма по каждой позиции и общий итог в сомах.
- Очистка заказа.

## Как собрать APK
1. Откройте папку проекта `KavKevCalculator` в Android Studio (Hedgehog или новее).
2. Дождитесь синхронизации Gradle.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется JDK 17 и Android SDK 35. Интернет нужен при первой загрузке зависимостей Gradle.

## Важно о прайс-листе
Цены переписаны с фотографии. Рукописные количества и итоговая сумма с чека не внесены как значения по умолчанию: заказ начинается с нуля. Перед использованием проверьте позиции и цены, особенно плохо читаемые названия.
